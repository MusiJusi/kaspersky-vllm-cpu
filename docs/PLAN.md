## Порядок работы

Работа идёт по зависимостям этапов, без календарного расписания. Результаты
подтверждаются фактическим запуском. Kustomize и initContainer включены
в архитектуру сразу, так как они упрощают конфигурацию и разделение прав.

## Структура проекта

```text
Dockerfile                  # основной CPU-сервис
requirements.txt            # полный lock Linux/CPU зависимостей
downloader/
  Dockerfile                # лёгкий rootless initContainer
  requirements.txt          # зависимости загрузчика
src/                        # загрузка, запуск и настройка логирования
k8s/
  base/                     # основные ресурсы Kubernetes
  overlays/local/           # локальная конфигурация Kustomize
scripts/                    # проверки окружения, API и нагрузки
docs/                       # план и критерии приёмки
README.md                   # проверенная инструкция
```

Результаты фактических проверок и ограничения приведены в [VALIDATION.md](VALIDATION.md).
